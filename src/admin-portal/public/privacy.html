Zava Scrum Agent privacy notice

This is a demonstration proof of concept operated by James Ford, not a production service. Use demonstration data only.

The agent uses your Entra identity to resolve team membership. Copilot sprint questions read Azure DevOps using your own delegated permissions. Access tokens are not written to the application store or included in model prompts.

The application stores team settings, roster identities, session lifecycle, approved follow-ups and an approval audit trail in the deployment's Cosmos DB. The ACS and Simulated Room paths can store transcripts, commitments and recaps. The native Graph media path does not store meeting-derived audio, transcripts, attendance or proposals.

Foundry models process authorised prompts to phrase answers and facilitate ceremonies. Copilot introductions receive only a computed summary and its authorised team identifier; cited work item content is rendered by code. Teams messages and Azure DevOps data remain subject to those services' retention policies.

No data is sold or used for advertising. A deployment administrator controls access and demo reset; demo reset is not deletion of the approval audit trail. Contact the repository owner through the project issue tracker for access, correction or deletion requests. Do not post private data in public issues.
