## Decision

Keep Acs/Share/Direct, Simulated Room and stable hosted4. Retain native and
hosted alternatives without promoting them or adding a stand-in. Record
latest and historical failures separately, preserve raw evidence, and retry
only the failed retrospective suite unchanged. Do not rerun passing aggregate
suites, tune goldens, thresholds, prompts or Domain rules, or treat a retry
as proof that the first failure did not happen.

Separate configured test outcomes, post-deploy readiness and formal acceptance.
The portal has zero configured tests; native human/media, Copilot, knowledge,
Work IQ and the complete multi-team matrix have no new live samples.
G8 remains failed: eastus2 D4s_v5 is unavailable for this subscription despite
quota0/100used, and active privileged deployer authority is unproven.
No G8 operation, provisioning, consent mutation or adapter selection occurs.
Existing exact human actions and owners remain in DEPLOY.md.

## Consequences

Passing builds and portal approval are not an all-green release. Track the
retrospective model deviation as a live reliability risk even if a focused
retry passes; repeatable gateway/model investigation belongs to a separately
scoped follow-on, not speculative validation-step code. Owned local helpers
are stopped and their exact temporary data removed. The existing exact
board parity11/11 failure and model/date/latency failures remain visible.
No new platform API or infrastructure is introduced, so there is no new
platform-contract assumption. Fixed added resource cost USD0/hour; existing
synthetic model/voice calls incur variable consumption. Presenter Pack,
secrets, mcm, zavagf and deployed resource settings remain untouched.
